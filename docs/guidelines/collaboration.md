# Collaboration

Match the repository's existing collaboration conventions.

- Prefer short, imperative, lower-case commit summaries such as `refactor` or `update readme`.
- Use `release: vX.Y.Z` for version bump commits.
- Pull requests should include the problem, the chosen solution, and the commands used to verify the change.
- Mention user-visible CLI behavior changes explicitly.
- Include screenshots only when CLI output or packaged-shell behavior changes in a way that benefits from visual context.
